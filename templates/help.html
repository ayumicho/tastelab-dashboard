About This Demo

This is a portfolio demo of the TasteLab Dashboard — a research analytics platform built for Breda University of Applied Sciences (BUas).

The original system processed live multimodal data (video, audio, sensor streams) from a physical sensory research lab. In this demo version:

  • All data is pre-loaded sample data based on real experiment structures.
  • The ETL pipeline connecting to the university's storage server has been removed.
  • The dashboard is hosted publicly on Render with a Supabase PostgreSQL database.
Note: Because this is sample data, you cannot add live experiments or sync new video data. The "Add Experiment" form is available to explore the UI.

The following features exist in the full BUas version but are not included in this demo:

  • MinIO ETL Pipeline: Automated sync from the university's object storage server.
  • Manual Annotation: A labeling interface used to train the person re-identification model.
  • Live Video Streams: Synchronized feeds from 6 cameras in the research lab.
  • Dagster Processing Pipeline: Background orchestration for video and audio analysis.

Features

  • Experiments Dashboard: Browse, filter, and manage sensory research sessions.
  • Speech-to-Text Analysis: View AI-generated transcripts, summaries, detected questions, action items, and emotion timelines.
  • Detection & Tracking: Explore movement heatmaps and participant tracking across camera zones with a playback timeline.
  • Single Experiment View: A combined overview of both speech analysis and tracking data for any experiment.

Understanding Results

The heatmap visualizes movement density in the research room based on tracking data across 4 camera zones.

  • Red Areas: High traffic — participants spent a lot of time here.
  • Green/Blue Areas: Low traffic — participants passed through quickly.

Use the Timeline Slider at the bottom of the tracking page to replay movement and see where participants were at specific timestamps.

The dashboard uses NLP (Natural Language Processing) to determine the emotional tone of the recorded conversation from each experiment.

  • Positive: Happy, Excited, Grateful.
  • Negative: Angry, Disgusted, Worried.
  • Neutral: Standard conversation.

The Speech-to-Text page shows a full timeline of these emotions per transcript segment.

FAQ

The demo is hosted on Render's free tier, which may spin down after inactivity. The first page load can take up to 30 seconds while the server wakes up. If data still doesn't appear after that, try refreshing the page.

You can use the "Add Experiment" form to create a basic experiment entry. However, speech analysis and tracking data require the full processing pipeline which is only available in the original BUas deployment.

The portfolio version of this project is available on GitHub. Visit github.com/ayumicho/tastelab-dashboard to explore the codebase.
